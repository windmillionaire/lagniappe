This Owner-only section separates Lagniappe application identities from Google Cloud IAM and outside provider accounts. It shows only non-secret identity metadata already saved by setup.

{{ subheading("Handoff state") }}

“Application handoff configured” means the deployed settings name the permanent Owner as deployer and no longer allow automatic installer bootstrap. It does not by itself prove that every external permission was removed. Use the project IAM link to confirm the historical installer is absent there.

The installer normally runs ./setup.sh handoff from the installation working copy after the Owner has verified the application and removed the temporary Lagniappe Administrator role. If the installer is unavailable, the Owner may first recover a working copy from the downloaded lagniappe_settings.yaml, authenticate gcloud and Application Default Credentials as the permanent Owner, and run the same command.

{% call callout("warning") %} Do not suspend or delete a temporary installer account while it is still used to send authentication email or control billing, Redis, DNS, Cloudflare, Resend, recovery, or another provider. Transfer or reconfigure those dependencies first. {% endcall %} {{ subheading("Why there is no Remove IAM button") }}

The deployed application is intentionally not authorized to administer human Google Cloud access. Run ./setup.sh handoff from the installation working copy; it verifies and transfers the managed access before removing the installer’s direct project binding as its final cloud change.
