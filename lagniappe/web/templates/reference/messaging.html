{% call callout("tip") %} Lagniappe uses messages pushed from the server in order to manage collaboration between users. If you do not allow messages, forms and documents will still be collaborative, but you will be unable to see other users' changes. You also may see unexpected changes to forms and documents, as the changes other users make may overwrite your own. You can allow messages by clicking the button below. {% endcall %}
