{{ subheading("What This Panel Does") }}

Import Data uploads a CSV file and starts the import workflow. Once the file is uploaded, Lagniappe reads the rows and columns, then walks you through turning that spreadsheet into pages or tasks.

{% call callout("tip") %} This importer is for CSV files. Use it when you have a spreadsheet that should become structured records or task work inside Lagniappe. {% endcall %}
{{ subheading("What Happens Next") }}
{% call feature("CSV Processing", icon="file", kind="file") %} Lagniappe validates the upload, counts rows and columns, and prepares detected column types for the wizard. {% endcall %} {% call feature("Import Wizard", icon="form", kind="form") %} Open the uploaded import file to choose what kind of records to create, pick or build related forms, map columns, and verify the result. {% endcall %} {% call feature("Background Import", icon="run.active", kind="task") %} Larger imports can run as a background process so progress is tracked without keeping the upload panel open. {% endcall %}
{{ subheading("Before Uploading") }}
  • Use a header row with clear column names.
  • Remove blank rows and unrelated notes from the spreadsheet.
  • Keep one kind of record per CSV so the wizard can map columns cleanly.
