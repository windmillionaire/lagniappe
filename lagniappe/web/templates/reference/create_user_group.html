{{ subheading("What This Does") }}

User groups collect permissions under one name so the owner can grant the same access to multiple users. After you create a group, Lagniappe opens that group's permissions panel so you can decide what its members can view, edit, create, or manage.

{% call callout("tip") %} Groups are the cleanest way to manage recurring roles like Staff, Editors, Clients, Volunteers, or Project Leads. {% endcall %}
{{ subheading("How to Use It") }} {% call step(1, "Create the group") %}

Enter a short, recognizable group name based on the role or access pattern.

{% endcall %} {% call step(2, "Set permissions") %}

Use the permissions panel that opens after creation to grant only the access this role needs.

{% endcall %} {% call step(3, "Assign users") %}

Add users to the group from the create-user form or from an individual user's settings page.

{% endcall %}
{{ subheading("Good Group Design") }}
  • Prefer a few clear groups over many one-off groups.
  • Name groups by responsibility, not by a single person's name.
  • Start with low access and raise permissions when a workflow truly needs it.
