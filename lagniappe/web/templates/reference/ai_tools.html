{{ subheading("What This Panel Does") }}

AI Tools creates saved reports from uploaded context, workspace questions, or creation requests. A report can answer directly, explain what it found, and, when useful, propose changes you can inspect before running.

{% call callout("tip") %} Starting a report does not change your workspace. Proposed changes are saved first, and the deterministic runner only executes them if you choose to continue. {% endcall %}
{{ subheading("Available Tools") }}
{% call feature("Organize", icon="organize", kind="default") %} Drop files, paste screenshots, or add instructions when you want Lagniappe to decide how something should be saved. Organize can propose pages, tasks, forms, categories, projects, model tasks, file attachments, and summaries. {% endcall %} {% call feature("Ask", icon="ask", kind="default") %} Ask a question about your workspace. Ask can search permitted pages, tasks, projects, categories, forms, and files, then answer with links and cite the workspace context it used. If the answer naturally implies follow-up work, it can also propose actions. {% endcall %} {% call feature("Create", icon="create", kind="default") %} Describe what you want Lagniappe to create. Create can draft workspace structure and content as a saved proposal that you can revise, skip, or run manually. {% endcall %} {% call feature("Permissioned Context", icon="permissions", kind="user") %} AI tools use the same permissions as the current user. They should only see and propose work with records the user is allowed to access. {% endcall %}
{{ subheading("Report Flow") }} {% call step(1, "Choose a tool") %}

Use Organize for files and screenshots, Ask for a direct workspace question, or Create for new workspace content.

{% endcall %} {% call step(2, "Add context") %}

Upload files for Organize, or type the question or creation request you want the AI to consider.

{% endcall %} {% call step(3, "Review the prompt if helpful") %}

Use Initial Prompt to review the starting instructions and currently available context. AI may retrieve more permitted workspace context or search results while it works.

{% endcall %} {% call step(4, "Review the report") %}

Lagniappe saves the result in the Tools list so you can inspect the answer or proposal before taking action.
