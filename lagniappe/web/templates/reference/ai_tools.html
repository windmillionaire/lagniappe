{{ subheading("From Request to Result") }} {% call step(1, "Describe what you need") %}

Add instructions, files, or both, then choose Start. Name any records you want to use and explain what should happen to your files.

{% endcall %} {% call step(2, "Review the answer and proposed changes") %}

Open the saved plan to check the answer, file destinations, and each proposed action. A question with no changes is complete when its answer is ready.

{% endcall %} {% call step(3, "Revise or apply") %}

Before execution, use Revise Plan to ask for corrections or additions. When the proposed changes are right, choose Execute Proposal to apply them.
