{{ subheading("Visibility Options") }} {% call detail("Public Documents", kind="page") %} When a document is set to public, it becomes accessible to anyone with the URL, even without logging in. This is useful for sharing recipes, blog posts, tutorials, or any content you want to share with friends or the world. {% endcall %}
{% call detail("Private Documents", kind="default") %} Private documents can only be viewed by users with appropriate permissions. This is the default setting and recommended for personal notes, drafts, or anything you want to keep private. {% endcall %}
{{ subheading("Important Considerations") }}
  • Images embedded in public documents also become publicly accessible
  • Only the document content becomes public - other page information remains private
  • If you make a public document private, the URL will stop working
  • You can change visibility at any time, but consider who may have already bookmarked public links
{{ subheading("Best Practices") }}
  • Review your content carefully before making it public
  • Keep drafts and works-in-progress private until they're ready
  • Be mindful of embedded images and their privacy settings
  • Search discovery is controlled site-wide and can also be disabled for this page
  • Preview images can only be selected from images already used in this document
  • Search engines and social sites may retain cached copies after a page becomes private
{% endcall %}
