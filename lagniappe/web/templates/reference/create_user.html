{{ subheading("What This Does") }}

Creating a user gives someone access to your Lagniappe instance. Each user gets their own personal page where they can store notes, tasks, and files. You can control what else they can access through user groups and permissions.

{{ subheading("Page Attachment") }} {% call detail("Create New Page (Default)", kind="page") %} If you leave "Attach to Existing Page" empty, a new personal page will be created automatically for this user. This is the typical choice for new users. {% endcall %}
{% call detail("Attach to Existing Page", kind="default") %} If a page already exists for this person (maybe you created it before adding their user account), you can connect it here instead of creating a new one. {% endcall %}
{{ subheading("User Groups & Permissions") }}

How Groups Work

User groups are collections of permissions that make it easy to give multiple users the same access levels. You can add a user to multiple groups, and they'll get the highest permission level from any group for each resource.

{% call callout("warning") %} Permission Combining: If you add someone to multiple groups, their permissions will combine. For example, if one group gives them "View" access to recipes and another gives "Edit" access, they'll end up with "Edit" access (the higher permission). {% endcall %}

Default Access (No Groups)

Users without any groups can still access their own personal page and the homepage. This gives them a place to store their own notes and files while keeping everything else private.

{{ subheading("After Creation") }}
  • Users sign in with the Google account whose email address is on their user record.
  • Their personal page will be automatically created and accessible
  • You can adjust their permissions later by visiting their page as an administrator
  • They can be added to or removed from user groups at any time
{{ subheading("Best Practices") }}
  • Create user groups first if you plan to give multiple people similar access
  • Start with minimal permissions and add more as needed
