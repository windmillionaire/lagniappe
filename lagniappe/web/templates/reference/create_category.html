{{ subheading("What Categories Do") }}

Categories group related pages and give them a shared starting structure. A page can belong to more than one category, so categories work like flexible folders or tags.

{% call callout("tip") %} Use a category when several pages should share the same form, permissions, or filters. {% endcall %}
{{ subheading("Creation Options") }}
{% call feature("Generate or Manual", icon="generate", kind="category") %} Describe the category you want and let AI draft it, or switch to manual mode and choose the details yourself. {% endcall %} {% call feature("Default Form", icon="form", kind="form") %} Pick the page form new pages should start with. This also gives the category useful form-based filters. {% endcall %}
{{ subheading("Typical Flow") }} {% call step(1, "Name the category") %}

Use a name people will recognize when browsing or assigning pages.

{% endcall %} {% call step(2, "Choose structure") %}

Attach a default form when pages in the category should begin with shared structured fields.

{% endcall %} {% call step(3, "Create pages") %}

Add pages manually, generate starter pages, or attach existing pages later.

{% endcall %}
{{ subheading("Worth Remembering") }}
  • The category's default form is a starting point. Individual pages can use a different form.
  • Form filters work best when pages in the category use the category's default form.
  • Set permissions thoughtfully if the category contains private or sensitive pages.
