{{ subheading("What Model Tasks Do") }}

Model tasks are reusable task categories inside a project. They help split project work into phases, standard steps, or repeatable task types.

{% call callout("tip") %} When a model task has a form, tasks assigned to it can inherit that form for consistent data collection. {% endcall %}
{{ subheading("What You Can Do Here") }}
{% call feature("Create a Model Task", icon="add", kind="model-task") %} Add a new phase or task type to the project, such as Intake, Inspection, Approval, or Final Review. {% endcall %} {% call feature("Attach a Task Form", icon="form", kind="form") %} Choose a task form when every task in this phase should collect the same fields or status checks. {% endcall %} {% call feature("Open Status Views", icon="completed", kind="task") %} Use the Completed and In Progress links to jump to filtered task views for that model task. {% endcall %}
{{ subheading("Typical Flow") }} {% call step(1, "Create project phases") %}

Keep names short and action-oriented so the project is easy to scan.

{% endcall %} {% call step(2, "Attach forms only when helpful") %}

Use forms for structured details, approvals, or checklists, not for every simple task.

{% endcall %} {% call step(3, "Assign tasks") %}

When creating or editing a task, link it to the project and the right model task.
