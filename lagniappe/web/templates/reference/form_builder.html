{{ subheading("What the Builder Does") }}

The form builder lets you design the fields, layout, and behavior of a page or task form. Use the side panels to add components, configure the selected component, preview the result, and save changes.

{% call callout("tip") %} Build the form around the questions users actually need to answer. Short, clear forms are easier to fill and easier to filter later. {% endcall %}
{{ subheading("Builder Areas") }}
{% call feature("Components", icon="form", kind="form") %} Drag fields from the component list into the form. {% endcall %} {% call feature("Form Area", icon="builder.saved", kind="page") %} Arrange fields in the order users should complete them. {% endcall %} {% call feature("Settings", icon="settings.page", kind="form") %} Click a field to adjust its label, options, required state, and visibility rules. {% endcall %} {% call feature("Preview", icon="public", kind="project") %} Toggle preview to check how the form will feel before saving. {% endcall %}
{{ subheading("Quick Flow") }} {% call step(1, "Add fields") %}

Drag components into the form area or generate a draft from a description.

{% endcall %} {% call step(2, "Configure fields") %}

Select each field and set labels, choices, and rules.

{% endcall %} {% call step(3, "Preview and save") %}

Preview the form, make adjustments, then save when it is ready.
