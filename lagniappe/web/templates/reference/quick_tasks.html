{% from "manual/macros.html" import subheading, callout, step %} {% from "reference/macros.html" import modal, feature %} {% call modal("Quick Task Editing") %}
{{ subheading("Overview") }}

Quick task editing allows you to edit tasks directly in tables without navigating to individual task pages. Click the lightning bolt toggle to activate edit mode on any task table where you have edit permissions.

{{ subheading("How It Works") }}
{% call step(1, "Click to Edit") %}

Editable fields show a hover state. Click any field to start editing.

{% endcall %} {% call step(2, "Save Changes") %}

Changes save when you press Enter or click away from the field (blur).

{% endcall %} {% call step(3, "Cancel Edits") %}

Press Escape to cancel changes and return to the original value.

{% endcall %}
{{ subheading("Editable Fields") }} {% call callout("tip") %}
  • Task completion: Toggle checkboxes to mark tasks complete
  • Due dates: Click date fields to update deadlines
  • Text inputs: Edit text and number fields from attached forms
  • Checkboxes: Toggle yes/no values from form fields
{% endcall %}

Complex form fields (file uploads, dropdowns, signatures) are not available in quick edit mode and require the full task form.

{{ subheading("Permissions & Limitations") }}
{% call feature("Read-Only Tasks") %} Tasks you can't edit appear grayed out and won't respond to clicks. This typically indicates a permissions restriction. {% endcall %} {% call feature("Field Availability") %} Only simple form fields appear in edit mode. Fields that don't show up require more complex interactions available in the full task form. {% endcall %}
{% endcall %}
