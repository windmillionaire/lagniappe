{{ subheading("What This Form Does") }}

This panel creates a new form and adds it to the Form Index. A form is a reusable set of fields that can collect structured information on pages or tasks.

{% call callout("tip") %} Pick the form type based on where the form will be used: page forms describe records, while task forms guide work that needs to be completed. {% endcall %}
{{ subheading("Form Types") }}
{% call feature("Page Form", icon="page", kind="page") %} Use page forms for information that describes something: contacts, inventory, clients, recipes, reference records, or anything you want to filter on a category page. {% endcall %} {% call feature("Task Form", icon="task", kind="task") %} Use task forms for process checklists, approvals, inspections, intake workflows, and other work where completion status matters. {% endcall %}
{{ subheading("After Creation") }} {% call step(1, "Name the form") %}

Use a name that will make sense when attaching it to pages, categories, projects, or model tasks.

{% endcall %} {% call step(2, "Choose Page or Task") %}

The type controls which components are available in the builder and where the form can be attached.

{% endcall %} {% call step(3, "Build the schema") %}

Open the new form from the index to add fields, configure settings, and preview the finished form.

{% endcall %}
{{ subheading("Good Defaults") }}
  • Start small. Add the fields users truly need, then expand once the workflow is clear.
  • Use clear names and descriptions for values people will look up later.
  • Use required fields carefully on task forms because they can block task completion until filled.
