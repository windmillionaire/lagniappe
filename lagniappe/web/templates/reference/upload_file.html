{{ subheading("What This Panel Does") }}

Upload File attaches a file to the current page. You can upload a new file or link an existing file you already have access to.

{% call callout("tip") %} The original file is preserved. Processing options add extra indexed or readable content without changing the upload itself. {% endcall %}
{{ subheading("Upload Choices") }}
{% call feature("Choose or Drop a File", icon="upload", kind="file") %} Upload documents, images, PDFs, text files, spreadsheets, or other attachments from your device. {% endcall %} {% call feature("Link Existing File", icon="link", kind="file") %} Reuse a file that is already in Lagniappe instead of uploading a duplicate. {% endcall %} {% call feature("Text Extraction", icon="text", kind="file") %} For supported files, extract readable text so it can be viewed and optionally searched. {% endcall %} {% call feature("AI Summary", icon="generate", kind="file") %} Generate a short description that helps people understand the file at a glance. {% endcall %}
{{ subheading("Typical Flow") }} {% call step(1, "Pick the file") %}

Upload a new file or select an existing one.

{% endcall %} {% call step(2, "Choose processing") %}

Enable text extraction, summaries, and search only when they are useful.

{% endcall %} {% call step(3, "Review the file page") %}

Open the file to download it, edit details, view extracted text, or check processing status.

{% endcall %}
{{ subheading("Privacy Notes") }} {% call callout("warning") %} Files follow the permissions of the pages they are linked to. Public files can be opened by anyone with the direct link, so use public visibility carefully. {% endcall %}
