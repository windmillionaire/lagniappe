Site Settings is the Administrator control panel for this Lagniappe instance. It is where you handle maintenance tasks, manage Administrators, save deployment preferences, jump to provider dashboards, and manage the public app icons. Only the primary Owner can open secret-bearing Configuration or change the Administrator roster.

Most changes here are not everyday edits. They are meant for setup work, troubleshooting, upgrades, and the handful of settings that affect the whole application.

{% call callout("tip") %} Each section has its own help button. Use those for the practical details before clicking a maintenance action or changing deployment settings. {% endcall %} {% endcall %}
