{{ subheading("What This Panel Controls") }}

User Settings manages the user account connected to this personal page. Depending on your role, it can show account details, sign-out actions, and the groups that grant this user access.

{% call callout("tip") %} A user's groups are their normal access path. Add or remove groups here when someone's role changes. {% endcall %}
{{ subheading("What You Can Edit") }}
{% call feature("Name", icon="user", kind="user") %} The user name identifies the account connected to this page. Page details stay in the main Info panel. {% endcall %} {% call feature("Email", icon="email", kind="user") %} Owners can update another user's account email. Nobody can change their own email address here. {% endcall %} {% call feature("User Groups", icon="group", kind="user") %} Owners and admins can add the user to one or more groups, or remove groups they no longer need. {% endcall %} {% call feature("Sign Out", icon="logout", kind="user") %} On your own user page, this panel includes the sign-out action. {% endcall %}
{{ subheading("Worth Remembering") }}
  • Group membership controls broad access; page restrictions control exceptions on individual pages.
  • If access looks stale after changing groups, the user may need to sign out and back in.
  • The site owner cannot restrict their own owner access.
