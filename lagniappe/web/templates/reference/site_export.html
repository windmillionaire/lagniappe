{% from "manual/macros.html" import callout, subheading, step %} {% from "reference/macros.html" import modal %} {% call modal("HTML Archive Export") %}

HTML Archive creates a read-only copy of the workspace for safekeeping or use outside Lagniappe. It runs in the background, so you can leave this panel while it is being built.

{% call callout("warning") %} This is an Administrator tool. The archive can include workspace content and files, so treat its storage location and download command as sensitive. {% endcall %} {{ subheading("Create and Download an Archive") }} {% call step(1, "Start Export") %}

Select Start Export. Lagniappe creates a dated archive in the configured storage bucket.

{% endcall %} {% call step(2, "Wait for completion") %}

The status changes as the background job runs. A notification appears when it completes or fails.

{% endcall %} {% call step(3, "Use the download command") %}

When complete, copy the displayed gcloud storage cp --recursive command to download the archive. The Entry path identifies its index.html file.

{% endcall %} {{ subheading("Archive Details") }}

Each entry shows its status, object count, size, Cloud Storage location, entry page, and download command. If an export fails, its error is shown in the same entry; start a new export after resolving the reported issue.

{% endcall %}
