{{ subheading("What This Panel Controls") }}

Page restrictions narrow who can view this specific page. They are useful when a page belongs to a broad category but should only be visible to administrators or selected groups.

{% call callout("warning") %} Users need normal category access and must match at least one of the page's listed groups. If its form also lists groups, users must match at least one of those as well. Administrators can always view restricted content. {% endcall %}
{{ subheading("What You See") }}
{% call feature("Page Restrictions and Form Restrictions", icon="group", kind="user") %} Each row shows that source's groups or administrator-only setting. Sources with no restrictions are hidden. When both rows list groups, users must belong to at least one group in each set. {% endcall %} {% call feature("Administrators Only", icon="siteOwner", kind="user") %} Use this for Administrator-only pages that should be hidden from every group. {% endcall %} {% call feature("Group Restrictions", icon="users", kind="user") %} Add or remove groups, then click Save Restrictions to apply your changes. On a user's page, use Update User Settings. {% endcall %}
{{ subheading("Good Fit") }}
  • Use restrictions for exceptions, private records, or sensitive pages inside otherwise shared categories.
  • Use category or group permissions for broad access patterns that apply to many pages.
  • Remove page restrictions to use normal category access and any restrictions on the page's form.
