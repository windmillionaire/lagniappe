{{ subheading("What This Panel Controls") }}

Page restrictions narrow who can view this specific page. They are useful when a page belongs to a broad category but should only be visible to the owner or selected groups.

{% call callout("warning") %} Restrictions override category access. If a page is restricted to the owner or to a group, other groups that can normally see the category will not see this page. {% endcall %}
{{ subheading("What You See") }}
{% call feature("Visible To", icon="group", kind="user") %} The badges show who currently has access through the page's restrictions. {% endcall %} {% call feature("Restrict to Site Owner", icon="siteOwner", kind="user") %} Use this for Administrator-only pages that should be hidden from every group. {% endcall %} {% call feature("Group Restrictions", icon="users", kind="user") %} Add one or more groups when only those groups should be able to view the page. {% endcall %}
{{ subheading("Good Fit") }}
  • Use restrictions for exceptions, private records, or sensitive pages inside otherwise shared categories.
  • Use category or group permissions for broad access patterns that apply to many pages.
  • Remove restrictions when the page should go back to normal category-based visibility.
