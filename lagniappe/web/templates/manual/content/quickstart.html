Lagniappe starts at Home, where you can open a recent list, create something new, or jump into the workspace directory. Once you open a record, colored icons switch between the information, documents, tasks, and files that belong to it.

{% call callout("tip", False) %} Controls only appear when they apply. If an icon described here is missing, your account may not have permission to use it or the control may not apply to the current content. Many icon-only action controls also show their name when you hover on desktop. {% endcall %} {% endcall %} {{ heading("When the Server Is Waking Up", icon="offline", kind="page") }} {% call card() %}

Lagniappe uses basic scaling by default, which lets App Engine stop the server after it has been idle instead of charging to keep it running all day. The first request after that is a cold start. The server usually takes less than a minute to become responsive.

While the server is waking up (or if you are offline), you can still view pages that have already been opened in this browser. The offline icon appears next to the search bar and inside the submit buttons of forms that cannot be submitted offline. Those buttons become available again when the server reconnects.

If immediate first-page responses matter more than the additional cost, the owner can choose automatic scaling under Admin, Settings, then Deployment. Follow the {{ link( url_for("manual.index", section="personalization"), "Deployment Settings" ) }} instructions to apply and deploy that choice.

{% endcall %} {% call disclosure( "Forms and the form builder", "Define reusable structured fields, then attach the form to pages or tasks where people enter data.", "form", "form" ) %}

A form is a reusable schema, not a filled record by itself. Opening a row in the Form Index opens the desktop builder. Page forms describe a page; task forms record work and can preserve a new submission in each task completion.

{{ guide_item("form", "Components", "Drag field types from the left into the form, then select a field to configure it.", "form") }} {{ guide_item("settings.page", "Settings", "Changes the selected field, form-level options, conditions, and access restrictions.", "form") }} {{ guide_item("form", "Preview switch", "The pill switch at the top shows how the finished form will look and behave without saving it.", "form") }} {{ guide_item("builder.unsaved", "Builder save", "Cloud alert means the schema has local changes. When filling a form on a page or task, edit the fields and use its Save or Update button. Saved changes can refresh other open viewers, but unsaved typing is local and is not collaborative document editing.
