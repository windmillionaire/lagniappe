{% call card() %}

More than one person can work in the same workspace at the same time. Documents and forms update live for everyone looking at them, and you can keep working when your connection drops.

Collaboration follows the same access rules as everything else: people only see and edit the records their permissions allow.

{% endcall %} {{ heading("Live Documents", icon="document", kind="page") }} {% call card() %}

A page or project document can be edited by several people at once. Changes appear as they are made, and each person's edits show in their own color so it is clear who is writing where.

Concurrent edits merge rather than overwrite each other, so two people typing in the same document do not clobber one another's work or need to take turns.

{% endcall %} {{ heading("Live Forms", icon="form", kind="form") }} {% call card() %}

Form fields stay in sync between everyone viewing the same page or task. When someone else changes a value, it appears for you within a second or two without reloading the page. This keeps a shared record consistent when two people happen to open it together.

{% endcall %} {{ heading("Presence", icon="users", kind="user") }} {% call card() %}

When others are viewing the same document or form, you can see who is there. That makes it easy to notice when a colleague is already working on the same record before you both start editing.

{% endcall %} {{ heading("Offline and Installable") }} {% call card() %}

Lagniappe keeps working when the network does not. If your connection drops mid-edit, document changes and form submissions are queued on your device and replayed when you come back online, so a brief outage does not cost you work.

It is also a progressive web app, so you can install it straight from the browser and run it like a native app -- pinned to a phone or tablet home screen, or opened from the desktop in its own window. Installed or not, it caches what it needs to stay responsive between requests.

{% endcall %} {{ heading("How Updates Travel") }} {% call card() %}

Because Lagniappe runs on App Engine, open views check a single adaptive polling endpoint rather than holding a persistent connection. Document editors and active background jobs check quickly; quiet views progressively check less often.

{% call callout("tip", False) %} Polling pauses while a tab is hidden or offline and runs immediately when the tab becomes visible or reconnects. Updates may arrive a few seconds later than a persistent real-time connection. {% endcall %} {% endcall %} {{ heading("Good to Know") }} {% call card() %}
  • Live editing and presence work best for a handful of people on a record, not large simultaneous crowds.
  • Offline edits are held on the device that made them; they replay from that device when it reconnects.
  • Visibility still comes from permissions -- collaboration never widens who can see a document or form.
  • This is shared editing of ordinary records, not a full real-time design canvas or a chat tool.
