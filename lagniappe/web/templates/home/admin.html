Run backup and restore commands from the installation checkout. Restores must be run with the CLI. The check command performs the restore preflight without changing data.

Point-in-time recovery and automatic backups stay inside Google Cloud and are available only for their retention window. A portable archive is an independent, downloadable copy of a manual backup with portable data, documents, and files. It can be validated without Google access, but it is not itself the source used by the restore command.

Archive validation is a read-only, offline integrity check. It verifies the manifest and checksums, portable data schema and relationships, local viewer links, and saved-file inventory. Pass the directory or ZIP path printed when the archive was created; replace the default path above when a custom output path was used.
