Assign Columns

Form: {{ file.form.name }}

Assign the columns to the form fields. You can edit this form before importing the data. Ignored columns will not be imported.

  • {{ render_icon("info", "text-kind-default", "form") }} If you add two columns to the same field, the values in those columns will be combined and separated by a space.
  • {{ render_icon("info", "text-kind-default", "form") }} If you add columns to table fields, those column values will be added to the table as new rows in the order they appear in the file.
    • {% if file.entity_type == "task" %}
  • {{ render_icon("info", "text-kind-default", "task") }} Each row creates a new task. Columns assigned to the 'Task Name' field are combined and used as the saved task's name. If a column is assigned to the 'Completed On' field, the task will be marked as completed on that date. If multiple columns are mapped to 'Completed On', those dates will be applied only to that new task to create its completion history; rows are never combined. The other data from that row will be copied into those history records. If a column is assigned to the 'Due Date' field, the task will be set to be due on that date. If multiple columns are assigned to the 'Due Date' field, the earliest due date will be used.
  • {{ render_icon("info", "text-kind-default", "page") }} In the next step, you'll be able to choose which column will be used to match tasks to pages. If that column maps to the page's name, you can set that here, otherwise it can be set to a field in that page's form in the next step. It is fine to ignore that column in this step if it does not map to a task form field or the page's name.
    • {% endif %}
