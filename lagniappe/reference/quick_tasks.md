Edit table lets you update supported task and page cells directly inside index tables without opening every record individually.

Look for **Edit table** in the **Active Tasks** (`/tasks/`) header on desktop, or **Category actions → Edit table inline** inside a Category. See [Tables and Inline Editing](/help/tables) for table overview and column controls.

## Inline editing and keyboard controls

- Activate **Edit table** (or **Edit table inline**) and click any editable cell. Live completion checkboxes work directly in tables at all times.
- Press **Enter** to save a cell, **Tab** to save and advance to the next editable cell, or **Escape** to cancel the active edit; clicking another cell also attempts to save the active field.
- Saving a value closes the cell and flashes a brief confirmation checkmark; if validation or permissions reject the edit, the cell stays open with an error message below it.

## Limits and conflicts

- Inline cells only allow edits supported by your permissions, field type, and current row state—open the full task form whenever a richer control (such as tables or complex inputs) is needed.
- Read-only tasks, completed submissions, and tasks paused during a background form update cannot be edited inline.
