**Edit table** enables supported inline updates in task tables. It is useful for small changes without opening each full task form.

## Edit and save

Activate Edit table, then select an editable cell. Press **Enter** to commit or **Tab** to commit and move to the next available field. Press **Escape** to cancel the active edit. Moving to another cell also attempts to commit the current value.

Completion checkboxes and supported form cells have their own inline controls. A field's type, permissions, and the table's current state determine whether it can be edited. Open the full task form when the required control is unavailable in the table.

## Restrictions and conflicts

A read-only task does not become editable when table editing is enabled. Completed submissions and work paused by a background form update may also limit editing.

After you press **Enter** or **Tab** to save a changed value, the cell closes and briefly shows a checkmark. If saving fails, the cell stays open and shows an error below the input.
