Pages are the records where information and work belong. A page can contain form values, a document, files, notes, tasks, category links, and an identifying image.

## Create a page

1. Open the page creation control from a category or Home.
2. Enter a clear name and optional description.
3. Choose a page form if the record needs structured fields. A category's default form can be preselected.
4. Create the page, or use available AI autofill to draft its form values from the supplied context.

Open the new page's **Info** tab to read any values filled by AI. Edit anything incorrect and choose **Update Page** to save your corrections. The page's other tabs let you add documents, files, tasks, and category links.

You can create pages in categories you can edit. Creating a new category requires its own permission. A page's category membership and any page or form restrictions determine who can see it; adding a category is therefore an access decision as well as an organizational choice.
