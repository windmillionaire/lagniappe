Pages hold everything about one subject, item, client, or person—structured form details, tasks, files, notes, category links, cover images, and a document.

You can create pages in any category where you have edit access.

## How to create a page

1. Open **New Page** (`+`) from a **Category** header or from **Home → Pages**.
2. Choose a **Category** (if creating from Home), enter a clear name and optional description, and review the suggested forms—category pickers highlight **Forms In This Category** when a category uses a default or common page form.
3. Select a page form if you want structured fields right away, and optionally use **AI autofill** (when enabled) to draft field values from context you provide.
4. Create the page, then open its **Info** tab to review or adjust any autofilled fields (**Save** / **Update**), attach files, add tasks, or write in its **Document**.

## Access and category membership

Creating pages inside an existing category requires edit permission on that category; creating an entirely new category uses its own creation permission. Because a page's category links—together with any page or form restrictions—govern who can view it, picking a category is both an organizational and an access decision.
