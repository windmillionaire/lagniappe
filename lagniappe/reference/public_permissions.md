Public Permissions govern limited access for signed-in people who have not become ordinary managed users. This is different from the anonymous access provided by a published page document.

A public user can sign in when the installation allows public access, but does not receive the normal managed-user group grants. The User Index can display public accounts separately through its public-users control.

## Configure limited access

Use the **Public** permissions panel to choose which categories, projects, and pages public users can access. These choices apply to all public users.

When a person is adopted as a managed user or assigned ordinary group membership, their access follows that account's normal permissions instead of the public group. Public accounts do not have the same collaboration or external-agent access as managed users.

Making a page document public is a separate publishing action. It does not add the page's private tasks, form answers, or uploads to the signed-in public-permissions policy.
