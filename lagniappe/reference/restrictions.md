Restrictions narrow access to particular pages or forms in addition to ordinary permission grants. They are useful for sensitive records inside a broadly shared category.

## How restrictions combine

An ordinary user needs the normal permission to view the content and must satisfy every applicable restriction source. Within one source, membership in any listed group is enough. When both a page and its form list groups, the user must match at least one group in each list.

**Administrators Only** hides that content from ordinary group members. Application Administrators, including the Owner, bypass these content restrictions.

Task and file access can inherit restrictions from their related page and forms. Assignment or an additional link is not a way around an applicable restriction.

## Change restrictions

Use the available restriction controls to select groups or Administrator-only access, then choose **Save Restrictions**. On a user page, the relevant settings are submitted through **Update User Settings**.

The display separates page and form sources and hides unrestricted sources. Removing a page restriction restores normal grants subject to any remaining form restrictions. Use group permissions for broad roles, and restrictions for narrower exceptions.
