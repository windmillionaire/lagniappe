Initial Prompt shows the instructions and workspace information sent at the start of an AI request. Open it to see which records, attachments, and instructions the request began with.

The actual preview can contain information from your account, selected records, and attachments. It is available only through the authorized feature that prepared that request; general help and search contain this explanation rather than the live prompt.

AI may retrieve more permitted records, file content, schemas, or help articles while working. The starting prompt is therefore not a complete transcript of every later tool result or provider exchange.

The saved plan shows the answer and proposed actions. If the proposed changes or file destinations are wrong, use **Revise Plan** to explain what should change before choosing **Execute Proposal**. Opening Initial Prompt does not change workspace records.
