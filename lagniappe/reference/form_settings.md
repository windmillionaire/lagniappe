The builder's Settings panel configures the selected component. Its controls vary by component type; select a field in the form area to see the available choices.

## Common settings

- **Title** is the visible field label. Make it clear what the person should enter.
- **Placeholder** shows an example before entry; it disappears as the person types.
- **Required** can block completion of a task until the necessary answer is present.
- **Input Type** selects appropriate display and validation for text, numbers, dates, and other supported values.
- **Options** defines the choices for radio and select fields. Configure **Multiple** when a select should accept several choices.
- **Visibility** shows or hides a field based on supported values in other fields.

Conditions attached to one controlling field are alternatives; conditions on different controlling fields must all match. In **Preview**, change the controlling answers to see which fields appear and which status messages are shown.

Table components have their own columns and column settings. Configure destination columns and choices before converting existing values. Replace and Delete are draft operations whose effects on saved answers take place when the form is saved.
