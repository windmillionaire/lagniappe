Projects collect related tasks while each task remains on its original page. Use a project to track shared work, recurring processes, or tasks spanning several records.

## Create a project

1. Open project creation on Home and enter a name and optional description, or describe the workflow for AI generation when available.
2. Add model tasks if the workflow has reusable phases or task types, such as Intake, Review, or Approval.
3. Attach task forms to model tasks when repeated work should collect the same information.
4. Link real tasks to the project or its model tasks and use project views to follow progress.

A project can begin as a simple collection without model tasks. Its document provides space for shared instructions, and filters can show work by status, assignment, dates, or available form values.

Project membership provides another way to find tasks. It does not move them off their pages or automatically grant permission to edit their originating pages. Keep task ownership, assignment, and restrictions in mind when sharing a project.
