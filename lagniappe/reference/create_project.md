Projects pull related tasks together across pages and optionally define reusable Model Tasks and a shared Project Document.

Tasks attached to a project stay on their originating pages—projects give your team one coordinated view of progress without moving records out of context.

## Creating and organizing a project

1. Open project creation from **Home → Projects (+)**, enter a name and optional description, or describe the workflow for AI generation when available.
2. Add **Model Tasks** in the left **Model Tasks** panel if the process repeats standard steps (such as Intake, Review, or Approval), reorder them as needed, and attach task forms where repeated work collects consistent answers.
3. Link real tasks to the project or its model tasks, filter by status (**Completed** / **In Progress** in Model Tasks, or live filters under **Tasks**), and use **Document** (with desktop **Expand** for full-width reading/writing) for shared instructions.

## Managing an open project

Click the project title for **Project actions** (**Rename**, **Add description** / **Edit description**, **Star**, **Delete**) and use **Settings** to manage access restrictions. Keep in mind that adding tasks to a project lets project members discover matching tasks according to permissions, without automatically granting edit access to the underlying pages.
