Search finds accessible workspace records and general Lagniappe help across names, descriptions, indexed document text, form values, and searchable file content.

Type a few distinctive words into **Search...** in the top-right header (click **×** inside the box to clear), pick a suggestion, or press Enter for the full results page.

## Narrowing results with facets

- Use the facet tabs on the search results page to focus on categories, projects, pages, tasks, files, forms, users, or **Help**. Task results also include project model tasks.
- Clear a selected facet anytime to return to all matches.
- Result snippets highlight matching text; a Help match on title or keywords shows its opening summary.

## Ranking, Help results, and selectors

- **Ranking weights**: Results blend text relevance with record-type emphasis. Category, project, and page name matches receive extra weight; **Help** articles are weighted below tasks and above files as a preference rather than a rigid grouping.
- **Help articles**: Help hits appear with a question-mark icon (`?`), open standalone articles whose **Close** button returns Home, and are readable by any signed-in user without granting administrative powers.
- **Record selectors vs. structured Filters**: Record pickers inside forms search eligible workspace records by name and never include Help articles. When you want to filter by dates, assignees, or exact form answers, use [Category and Project Filters](/help/filters) instead.
