Search finds accessible workspace records and general Lagniappe help. It can match names, descriptions, indexed document text, form values, and searchable file content.

## Search and narrow results

Enter a few distinctive words in the header search box. Select a suggestion or open the full results page. Result snippets show matching content; a help result with a title-only match shows its opening summary.

Use the full-page facets to narrow results to categories, projects, pages, tasks, files, forms, users, or **Help**. Task results also include model tasks. Clear selected facets to broaden the search again.

Ranking combines text relevance with record-type weights. Category, project, and page name matches receive extra emphasis; help is weighted below task results and above files. This is a preference rather than a fixed grouping by type.

Help results use a question-mark icon and open a standalone article. Close returns to Home. General administrator guidance is readable by signed-in users without granting administrative powers.

Record selectors inside forms search eligible workspace records by name. They do not include help articles. For structured conditions such as dates, assignments, and form answers, use category or project filters.
