Task history preserves completed work when a task is reopened. Each entry records the selected answers and their form generation, along with completion details, attachments, and related task context.

## Completed and original answers

Completing a task stores its original submission. A later form conversion can change the current displayed answers without changing that original or existing history.

Editors can use **View Original Submission** when a completed task's converted values differ from its original answers. If the live form was deleted, the task can offer an archived form view. Missing archived definitions are reported explicitly; loading an original or archived view does not save changes.

## Reopen a task

Manual reopening normally archives the current modified submission. Where original submission review is available, its choice lets you archive the original instead. Automatic reopening uses the original completion submission.

Reopening clears answer fields and completed checklist items for a fresh submission. The task's form, assignment, schedule, and page/project relationships remain. Earlier answers are not automatic defaults.

Use **Fill from latest history** to bring an available earlier value into an individual field. Review it, then use the normal Update or completion control to save. If the old value cannot be converted to the current field, the app reports the problem and retains the history.
