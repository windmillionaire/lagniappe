Creating a user sets up a managed account paired with a personal page for their tasks, notes, files, and account settings.

Open **Navigation → Users** and click **New User** (`+`) in the header to add a teammate (or use **User Groups** and **Show public/regular users** directly from the same header bar).

## Linking a page and setting access

- **Name and email**: Enter the person's display name and sign-in email.
- **Attach to Existing Page**: Leave this empty to create a fresh personal **My Page** for them, or pick an existing suitable page so you don't end up with duplicate records for the same person.
- **Groups and grants**: Add them to [User Groups](/help/user_groups) for the workspace areas they should access. Group and individual grants combine to use the strongest applicable permission; an account with no groups starts with only its own personal page.

## Sign-in and AI access

- Users sign in with email/password setup or with Google when enabled (matching the email saved on their Lagniappe user record). Creating a user record in Lagniappe and completing sign-in credentials are separate steps—see [Account Security](/help/account_security).
- New ordinary users start with **None** for site-funded AI. Administrators can raise ordinary accounts to **Ask** (questions) or **Create** (proposals and generation); only the Owner manages privileged Administrator accounts. Managed users can still use enabled external AI connections at any site tier, within their workspace permissions.
