Creating a user gives someone a managed account in this Lagniappe installation. Each account is connected to a personal page for their tasks, notes, files, and account settings.

## Account and page

Enter the person's name and sign-in email. Leave **Attach to Existing Page** empty to create a personal page, or select an existing suitable page to avoid creating a duplicate record for the same person.

Assign user groups for the workspace access they need. Group permissions combine with individual permissions, using the highest applicable grant. An account without group grants still has its personal page; account creation does not grant broad workspace access.

Users sign in through the installation's email/password flow. Where Google sign-in is enabled, their Google email must match their user record. Creating the Lagniappe record and establishing the person's sign-in credentials are separate steps.

## AI access

New ordinary users default to **None** for site-funded AI. Authorized Administrators can choose **Ask** for questions or **Create** for generation and proposals; Create includes Ask. Only the Owner manages privileged Administrator accounts.

AI access does not grant record permissions. Managed users can use an enabled external AI connection at any provider tier, subject to their ordinary permissions. Later account changes belong in User Settings.
