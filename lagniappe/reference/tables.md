Browse structured pages or tasks in index tables, pick visible columns, complete tasks in place, and edit supported cells inline.

Index tables appear inside [Categories](/help/create_category) (listing pages), [Projects](/help/create_project) (listing tasks), and **Active Tasks** (`/tasks/`). See [Search & Filters](/manual/search) for combining tables with live filtering.

## Checkboxes, sorting, and columns

- **Live completion checkboxes**: Task **Completed** checkboxes update the task right away without opening a separate screen.
- **Column sorting**: Click sortable headers to order rows.
- **Column visibility**: Use **Choose visible columns** on desktop or **Table controls** on mobile to show or hide form fields and metadata columns.

## Inline table editing

- **Categories**: On desktop, open **Category actions → Edit table inline** to edit supported page fields right inside table cells.
- **Active Tasks**: On desktop, use the **Edit table** header button in **Active Tasks** (`/tasks/`) for inline updates across open tasks.
- **Projects**: Project task tables support live checkboxes, sorting, and column visibility controls; inline cell editing (`Edit table inline`) is available on Category and Active Tasks tables rather than Project tables.
