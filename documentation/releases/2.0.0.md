# Version 2.0.0

## Required post-upgrade maintenance

Finish the software upgrade and deployment first. Setup does not run application
data migrations. Then sign in as the Owner and open **Admin → Site Settings →
Maintenance**:

1. Select **Apply Updates** to run the pending migrations, including **FIL-001:
   Single-owner Files** and **RST-001: Materialized local restrictions**.
2. Resolve any reported failures and rerun **Apply Updates** until it completes
   without failures. Files with conflicting or missing Page/Task owners and
   restrictions referencing missing groups require repair; the migration leaves
   those rows unchanged and remains incomplete until they are resolved.
3. Select **Refresh Cache** after the migrations finish. Keep the page open until
   the rebuild completes so search and permission indexes use the migrated data.
