# Version 2.5.0

- Added opt-in automatic execution of eligible plans and compact execution receipts for MCP clients.
- Setup and the application require Python 3.14. If a checkout has an older virtual environment, rename it and run setup again to create a 3.14 environment.
- Replaced per-symbol test annotations with application-wide Python type checks and stricter Ruff rules. Template, style, icon and mutation contracts still run in release validation. Test outcomes remain available in the tracked evidence manifest.
