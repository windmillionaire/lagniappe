# Version 2.5.0

- Added opt-in automatic execution of eligible plans, compact execution receipts, `update_category`, and confirmation-gated delete actions for MCP and API clients, and reduced in-app AI latency on text-only reports via shared tool schema reuse and lower thinking overhead.
- Expanded Remote MCP OAuth support to Claude (web and desktop), Claude Code, and Pi alongside ChatGPT, Codex CLI, and Antigravity, and hardened OAuth refresh handling against concurrent token refresh bursts.
- Added guided AI-assisted installation (`./setup.sh --agent`), a localhost browser Secret Vault so credentials stay out of chat history, and optional Google Cloud Secret Manager storage for runtime secrets (`./setup.sh secrets migrate`).
- Migrated all authored frontend modules to strict TypeScript with compile-time checking in local workflows and CI, fixing several UI and form-builder edge cases along the way.
- Added optional `LOGIN_NOTICE` text on `/users/login`, an optional read-only guest demo account (`DEMO_GUEST_EMAIL`), per-page directory ordering on `/public/`, and `data-nosnippet` on the hidden offline banner.
- Setup and the application require Python 3.14. If a checkout has an older virtual environment, rename it and run setup again to create a 3.14 environment.
- Replaced per-symbol test annotations with application-wide Python type checks and stricter Ruff rules. Template, style, icon and mutation contracts still run in release validation, and offline HTTP route tests run in a dedicated `tests_http` suite.
