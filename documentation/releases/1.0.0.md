# Version 1.0.0

## Required post-upgrade maintenance

After deploying this release, sign in as the Owner or an Administrator and
open **Admin → Site Settings → Maintenance**. Select **Apply Updates**,
resolve any reported failures, and then select **Refresh Cache**. `setup.sh
upgrade` does not run these application data updates.
