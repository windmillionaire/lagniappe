# Security Policy

## Supported versions

Security fixes are made for the latest tagged release and the current `main`
branch. Older releases are not supported; operators should upgrade before
requesting a fix for an older version.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or
pull request. Use GitHub's
[private vulnerability report](https://github.com/windmillionaire/lagniappe/security/advisories/new)
or email [security@lagniappe.site](mailto:security@lagniappe.site).

Include the affected version or commit, likely impact, reproduction steps,
relevant configuration, and a sanitized proof of concept when practical. Do
not include credentials, private user data, or access to a live installation.

Reports are handled on a best-effort basis. The maintainer will generally
acknowledge a report within seven days, investigate it, and coordinate public
disclosure after a fix is available. This project does not currently offer a
bug bounty.

Only test systems and data you own or are explicitly authorized to test. Do not
test maintainer or third-party deployments, provider infrastructure, or other
operators' data. Ordinary bugs and feature requests can use public GitHub
issues.
