# 04 — Related garden records

Operator-only. Stress natural-language entity selection, required versus
optional fields, action references, and a Task on a newly proposed Page.

## Preconditions and expected result

- The actor can create Categories, Page Forms, Pages, and Tasks. Do not turn a
  missing capability into a different job to make the run pass. Record existing
  same-name test records/proposals before the run.
- Propose a place named **MCP Trial Gardens 2026** for garden plots, with a
  reusable Page Form: required plot code and optional lead crop.
- Include a C-17 Page in that Category/Form, with lead crop okra, and an open
  Task to inspect its drip emitters on October 2 of the run's current year at
  8:30 AM actor-local time. In the reference timezone/year this is
  `2026-10-02T15:30:00Z`.
- References/dependencies make the four records executable together. Equivalent
  Form/Page names and dependency-safe action ordering are fine. No extra
  Project, file upload, or unrelated structure is needed.
- Submit a reviewable proposal with a usable link; do not execute it or claim
  the records are already live.

## Evidence and controls

Prompt unchanged from the same-named Desktop case. Round 2 produced the correct
proposal without validation repair, but three start-rate 429s inflated rounds
and time. Keep raw waits/retries in its measurements. The later limit patch was
not deployed during that run. See
[review](../../comparisons/mcp-round-2.md).
No attachments. Changing year/timezone or executing prior proposals changes
the comparison's starting conditions; record it rather than resetting the
living workspace automatically.
